# PetShop - Sistema de Gestión de Inventarios 🐾

Este es un proyecto personal que desarrollé como parte de mi aprendizaje en el desarrollo web. Se trata de una aplicación web para la gestión de inventarios en una tienda de productos para mascotas, construida con **Python** y el framework **Django**.

---

## 📌 Descripción

La aplicación permite:

- Registrar productos con nombre, descripción, precio y proveedor.
- Buscar productos por nombre o proveedor.
- Editar precios en masa filtrando por proveedor y porcentaje.
- Control de acceso: solo usuarios registrados pueden hacer cambios.
- Los superusuarios pueden crear nuevos usuarios y asignar permisos.
- Panel de administración incluido (Django Admin).
- Base de datos: SQLite (por defecto).

---

## 🛠️ Tecnologías Utilizadas

- **Backend**: Python + Django  
- **Base de datos**: SQLite  
- **Frontend**: HTML5 + CSS3 (diseño responsivo)  
- **Control de versiones**: Git + GitHub

3.Activá el entorno virtual:
.En Windows:
.\venv\Scripts\activate

.En macOS/Linux:
source venv/bin/activate

4.Instalá las dependencias:
pip install -r requirements.txt

6.Ejecutá el servidor de desarrollo:
python manage.py runserver

7.Accedé a la app desde tu navegador:
